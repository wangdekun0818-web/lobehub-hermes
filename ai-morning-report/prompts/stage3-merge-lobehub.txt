# 阶段 3 · 合稿（LobeHub 对话展示）

将 `YYYY-MM-DD` 替换为今日日期（Asia/Shanghai）。

## 任务
**禁止** `web_search` / `web_fetch`。只做读取、合稿、校验、**在本对话输出完整成稿**。

1. 从**本话题历史**读取前序分段（标记 `---分段:国际---` / `---分段:国内---` / `---分段:表格---` / `---分段:洞察---`）；若有文件工具则 read `memory/YYYY-MM-DD-*.md`
2. 按顺序合稿为完整日报
3. 合稿前执行**校验清单**（见下）；缺条时在对应章节补写或标注「未检索到」，**禁止**静默减少条数
4. **在本回复中直接输出完整 Markdown 正文**（含全部表格与解读），供用户在 LobeHub 对话页阅读。**禁止**说「请粘贴文件」「无法读取」「明天再发」；**禁止**投递飞书/外部渠道

## 合稿头部（固定）
```
# AI 情报日报 | YYYY-MM-DD

> 本日报由 LobeHub 自动生成 | 抓取时段：YYYY-MM-DD 08:00 CST
> 阅读提示：每条含「来龙去脉 + 概念解释 + 产业影响」，适合精读而非扫标题。
```

## 章节顺序
国际 → 国内 → 资本 → 工具 → 活动 → 机会洞察 → 数据板 → 今日一个概念

## 校验清单（合稿前必做）
| 检查项 | 要求 |
|--------|------|
| 国际动态 | 10 条 |
| 国内动态 | 10 条 |
| 资本表格 | 5 行 |
| 工具表格 | 8 行 |
| 活动表格 | 8 行 |
| 机会洞察 | 6 条 |
| 数据板 | 8 行 |
| 今日一个概念 | 1 篇 |

任一不满足：在合稿回复首段列出 `VALIDATION: 缺XXX`，并尽力补写。

## 输出
- **必须**在本对话一次性输出完整日报（超长可连续 2–3 条回复，但不得发摘要版）
- 末尾单独一行：`MORNING_REPORT_OK`
- 不要反问用户、不要要求用户上传文件

> 📌 *本日报基于固定源综合整理，每日 08:00 在本对话展示。*
